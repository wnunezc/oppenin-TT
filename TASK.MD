# PRUEBA PRÁCTICA: Creación de un skill de inteligencia artificial

Fuente: `PRUEBA TECNICA IT.pdf`, ubicado en este mismo directorio. Este archivo reproduce el enunciado completo con formato Markdown, sin añadir requisitos ni interpretaciones.

## 1. Crea un skill

Usando la herramienta de inteligencia artificial que tú prefieras (Claude, ChatGPT, Gemini, Copilot u otra), crea un "skill": un conjunto de instrucciones reutilizables que le enseñe a la IA a hacer una tarea específica de forma consistente.

Según la herramienta, puede llamarse Skill, GPT personalizado, Gem, Agente, Proyecto con instrucciones, etc.

El tema es libre, pero valoramos que sea útil para una empresa como la nuestra (diseño, fabricación e instalación de cocinas, closets y carpintería a medida).

## 2. Compártelo

Envíanos el skill de forma que podamos verlo y probarlo: el archivo, un link para compartirlo, o el texto completo de las instrucciones.

## 3. Explica para qué sirve

En un texto breve (**máximo una página**), explica:

- Qué problema resuelve y para quién.
- Cómo se usa (qué se le pide y qué entrega).
- Un ejemplo real de uso con su resultado.

## 4. Reporte de creación (hecho con IA)

Entrega un reporte, generado también con inteligencia artificial, que documente cómo creaste el skill. Debe incluir como mínimo:

- Fecha y hora de creación.
- Herramienta(s) de IA utilizadas y versión o modelo, si la conoces.
- Pasos que seguiste, de principio a fin.
- Principales instrucciones o prompts que usaste.
- Problemas que encontraste y cómo los resolviste.
- Pruebas que hiciste para validar que funciona.
- Cualquier otro detalle que consideres relevante.

Si tu herramienta lo permite, incluye también el link a la conversación o el historial donde lo construiste.
